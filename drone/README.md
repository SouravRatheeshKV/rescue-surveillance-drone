\# Rescue and Surveillance Drone



The drone component is designed to receive the emergency location and collect visual information from the specified location.



\## Main Components



\* ArduPilot APM 2.8

\* F450 frame

\* A2212 1000KV motors

\* 30A ESCs

\* FlySky FS-CT6B transmitter and receiver

\* Power module

\* Propellers

\* GPS NEO-7M

\* 3DR telemetry

\* LiPo battery

\* Camera

\* VTX and receiver



\## Software



The project documentation uses:



\* Mission Planner

\* T6 Config

\* Go FPV



\## Operating Concept



The emergency smartwatch provides the user's location. The location can then be used by the control system to direct the drone toward the required location.



The drone can collect images or video footage for use by the appropriate response personnel.
